# AlpacaHack 2100 ( 2025/12/1 )
## Description
🦙 < フラグは Daily AlpacaHack の 2100年1月 のカレンダーにあるパカ
## Solve
Descriptionの通り、フラグがDailyAlpacaHackの2100年一月のカレンダーにあります。
DailyAlpacaHackのカレンダーはクエリパラメーターのmonthを書き換えればすぐにその年月のカレンダーに飛べるので、わざわざ2100年まで「次の月」を推す必要はありません。
## Solver
```
https://alpacahack.com/daily?month=2100-01
```
